**How to use this in Universal Editor / your authoring doc:**
- Each block below is ONE section. In a Google Doc / Word doc, separate sections
  with a horizontal rule (type `---` on its own line and hit enter). Each rule
  becomes one of the footer's `<div>` sections.
- "Heading (H4)" means apply the **Heading 4** style to that line. The plain
  labels ("Quick Links", "KIA Social Media Links") stay as **normal paragraph**
  text — do NOT make them headings (that's how the code tells accordion columns
  apart from the always-open ones).
- Every list item is a normal bulleted list link.
- Replace the 8 placeholder "Copyright © 2021 Adobe…" divs on the existing
  `/footer` page with these 9 sections, then Publish.
