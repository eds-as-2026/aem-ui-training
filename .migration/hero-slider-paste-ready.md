# Kia Hero Slider — paste-ready content (12 slides)

**How to author in Universal Editor:**
1. Open the target page (e.g. the homepage) in Universal Editor.
2. Insert a **Hero Slider** block.
3. Inside it, add **12 "Slide" items** — one per slide below.
4. Each Slide has exactly **4 fields**:
   - **Desktop media** — pick the asset from the DAM (path shown as "Desktop media").
   - **Mobile media** — pick the mobile asset (path shown as "Mobile media").
   - **Content** — a heading (Title), a paragraph (Tagline), and a link (CTA).
     Add any disclaimer as a final paragraph starting with `Disclaimer` or `#T&C`.
   - **CTA button background** — the dropdown: choose **White** or **Navy** as noted.
5. **Publish** the page.

**Asset note:** media must live in the DAM at `/content/dam/aem-ui-gallery/`
(that folder path must match, or the media 404s on the live site). The CTA link
text is **Know More** on every slide.
